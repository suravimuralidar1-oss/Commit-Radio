Keyboard & Voice Navigation

Commit Radio can be operated without a mouse. Use the keyboard shortcuts below, or use voice commands when speech recognition is available.

Space Play or pause

N or → Next activity

P or ← Previous activity

R Repeat

D Read details

O Open on GitHub

S Stop speech

M Toggle microphone

+ / - Change speech speed

? Hear available commands

  • "Next"
  • "Previous"
